MultiHead Approach to Tasks:

1. Task Comes in
2. Auto-Decompose Process is run to break down the task
3. There is consensus vote on the tasks break down
4. For each task, best approach or ML solution is proposed
5. Best solution is voted on
6. Winning recipe is picked
7. Orchestrator executes the recipe including swapping heads that execute the tasks as it goes with local or remote or marketplace based resources via ACP
8. Execution completes and all resources are returned to the system
9. The entire interaction is stored in the knowledge data base in form of grounded claims
10. Night shift is run to extract useful knowledge from the claims in the data base and feed it back to decision making process
